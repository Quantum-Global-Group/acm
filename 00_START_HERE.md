## 🎯 Project Overview

**What You're Building:**

An autonomous marketplace where AI agents:
1. Request compute services → Consumer agents
2. Provide services → Provider agents
3. Settle payments in USDC → Real-time on Arc
4. Make independent decisions → Autonomous decision-making

**Why It's Special:**

- **50+ real Arc transactions** (not simulated)
- **≤ $0.01 per-action pricing** (traditional gas would be $1-5)
- **Autonomous agents** (both consumer and provider decide independently)
- **Economic proof** that Nanopayments + Arc enable agent commerce

**Tech Stack:**

- Smart Contract: Vyper on Arc EVM
- Backend: FastAPI (Python)
- Agents: Async autonomous agents
- Settlement: Circle Nanopayments + x402
- Testing: Comprehensive unit + integration tests
